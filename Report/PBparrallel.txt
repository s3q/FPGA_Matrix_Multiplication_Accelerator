Yes — what you want is **not systolic wavefront anymore**.

You want a **fully parallel dot-product architecture**.

## For 2×2

Instead of 4 PEs waiting for data to move, you build all 8 multipliers directly:

```text
C00 = A00×B00 + A01×B10
C01 = A00×B01 + A01×B11
C10 = A10×B00 + A11×B10
C11 = A10×B01 + A11×B11
```

All multiplications happen in the same cycle:

```text
Cycle 1:
8 multipliers active
```

Then add/register result:

```text
Cycle 2:
C is ready
```

So for 2×2:

```text
Systolic:       1, 3, 3, 1 active PBs
Fully parallel: 8 active PBs immediately
```

---

## For 8×8

To compute full 8×8 in one multiply stage, each output needs 8 multiplications.

```text
64 outputs × 8 multiplications = 512 multipliers
```

So if you only have about:

```text
87 DSP/PB blocks
```

you **cannot** compute the full 8×8 matrix in one cycle.

---

## What you can do with 64 PBs

With 64 PBs, you can do:

```text
one multiplication for every C cell per cycle
```

So for 8×8:

```text
Cycle 1: all 64 PEs compute k=0
Cycle 2: all 64 PEs compute k=1
Cycle 3: all 64 PEs compute k=2
...
Cycle 8: all 64 PEs compute k=7
```

Result ready after about:

```text
8 cycles + register/control overhead
```

This is different from systolic wavefront. It is more like:

```text
parallel output-stationary matrix multiplier
```

Each PE is tied to one output `C[i][j]`.

---

## Best architecture for your idea

Use:

```text
M × N active PEs
```

Each PE computes:

```text
C[i][j] += A[i][k] × B[k][j]
```

All active PEs run at the same time for each `k`.

For 2×2:

```text
4 PEs active
2 k-steps
≈ 2 cycles
```

For 8×8:

```text
64 PEs active
8 k-steps
≈ 8 cycles
```

This uses up to:

```text
64 multipliers
```

which fits your FPGA better than 512.

---

## Comparison

| Architecture               | 2×2 cycles | 8×8 cycles |               PBs used |
| -------------------------- | ---------: | ---------: | ---------------------: |
| Sequential                 |          8 |        512 |                      1 |
| Systolic wavefront         |       ~4–6 |     ~22–25 |               up to 64 |
| Output-stationary parallel |       ~2–3 |      ~8–10 |               up to 64 |
| Fully parallel dot-product |       ~1–2 |       ~1–2 | 8 for 2×2, 512 for 8×8 |

So your idea is valid, but for 8×8 the realistic version is:

```text
64 PEs active from the first compute cycle
repeat for K cycles
```

Not 512 multipliers.

---

## In your report, call it

```text
Output-Stationary Parallel Matrix Multiplier
```

or:

```text
64-PE Parallel Matrix Multiplication Accelerator
```

This is faster than systolic for small fixed max size, but it uses more routing because every PE must access A and B memories directly.
