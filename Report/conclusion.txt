So:

```text
Output-stationary is about 25 / 8 = 3.125× faster in cycles
```

But write the conclusion carefully:

> The output-stationary parallel architecture achieved lower latency than the systolic array because all 64 output processing elements were active from the beginning of computation, completing one full k-step per clock cycle. In contrast, the systolic array required additional cycles for wavefront filling, data propagation, and draining.

Also mention the trade-off:

```text
Output-stationary:
+ faster cycle count
- heavier routing / more direct data access

Systolic:
+ better data locality
+ more scalable
- extra fill/drain latency
```

Good report sentence:

```text
For the 8×8 test case, the output-stationary architecture completed the multiplication in 8 cycles, while the systolic architecture required 25 cycles. Therefore, the output-stationary design was approximately 3.1× faster in latency for this matrix size. However, the systolic array remains attractive for larger scalable designs because of its local data movement and lower routing complexity.
```
