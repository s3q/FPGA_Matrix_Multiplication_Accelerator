Yes, I understand now. You mean **PB utilization per clock cycle inside systolic operation**.

For your example:

```text
A = 2×3
B = 3×2
C = 2×2
```

Active PBs per cycle are:

```text
Cycle 0: 1 PB active
Cycle 1: 3 PBs active
Cycle 2: 4 PBs active
Cycle 3: 3 PBs active
Cycle 4: 1 PB active
```

So the systolic activity graph is:

```text
Active PBs
4 |        *
3 |    *       *
2 |
1 | *             *
0 +------------------
    0   1   2   3   4   Cycle
```

## Cycle-by-cycle PB activity

| Cycle | Active PBs | Operations             |
| ----: | ---------: | ---------------------- |
|     0 |          1 | PE00                   |
|     1 |          3 | PE00, PE01, PE10       |
|     2 |          4 | PE00, PE01, PE10, PE11 |
|     3 |          3 | PE01, PE10, PE11       |
|     4 |          1 | PE11                   |

So total multiplication operations:

```text
1 + 3 + 4 + 3 + 1 = 12 multiplications
```

That matches:

```text
M × K × N = 2 × 3 × 2 = 12
```

The difference is: instead of doing 12 operations one-by-one in 12 cycles, systolic spreads them like a wave and finishes in about 5 useful cycles.

For a **2×2 × 2×2** matrix, it becomes:

```text
Cycle 0: 1 PB active
Cycle 1: 3 PBs active
Cycle 2: 3 PBs active
Cycle 3: 1 PB active
```

Total:

```text
1 + 3 + 3 + 1 = 8 multiplications
```
